# Visa Map

Интерактивная карта мира: выберите страну паспорта и увидите визовый режим для каждой страны. Клиентское приложение без бэкенда, mobile-first, устанавливается как PWA. Интерфейс на русском.

Паспорта в MVP: Беларусь (BY), Казахстан (KZ), США (US). Спецификация: [`specs/initial.md`](specs/initial.md).

> **Информация справочная. Правила меняются, проверяйте на сайте МИД страны назначения.**

## Источник данных и лицензия

Данные берутся из [Passport Index Dataset](https://github.com/ilyankou/passport-index-dataset) (`passport-index-tidy-iso3.csv`), собранного с [passportindex.org](https://www.passportindex.org). Условия использования смотрите в лицензии этого репозитория; проект личный и некоммерческий. Если проект станет публичным сервисом или монетизируемым, вопрос лицензии нужно пересмотреть.

Поверх источника применяются ручные правки (`data-src/overrides.json`) и достраиваются территории (`data-src/territories.json`).

## Разработка

```sh
npm install
npm run build:data   # скачивает CSV и генерирует public/data (в git не коммитится)
npm run dev
```

Без сети можно указать локальную копию CSV: `PASSPORT_INDEX_CSV=/path/to/file.csv npm run build:data`.

| Команда                                       | Что делает                                                       |
| --------------------------------------------- | ---------------------------------------------------------------- |
| `npm test`                                    | unit-тесты (Vitest)                                              |
| `npm run test:e2e`                            | Playwright: десктоп + touch-профили (нужен `npm run build:data`) |
| `npm run lint` / `format:check` / `typecheck` | ESLint / Prettier / tsc                                          |

Для e2e один раз: `npx playwright install chromium webkit`.

## Как это устроено

- `scripts/build-data.ts` скачивает CSV, нормализует статусы, применяет оверрайды, достраивает территории, режет данные на 10 региональных чанков и пишет `public/data`. Формат источника изменился (неизвестное значение, страна без чанка) — скрипт падает, и деплой не выполняется.
- Клиент (`src/data`) загружает чанки параллельно, кэширует в IndexedDB (Dexie), версии чанков — хэши содержимого. Общие zod-схемы лежат в `shared/`.
- Карта: `d3-geo` (Natural Earth) + `world-atlas` 110m, жесты через `d3-zoom`. Страны, которых нет на карте 110m (Сингапур, Мальта и др.), рисуются маркерами (`src/lib/microStates.ts`).
- Названия стран и флаги строятся через `Intl.DisplayNames` и emoji, поэтому на Windows флаги отображаются буквами кода страны.
- Известное ограничение: Северный Кипр и Сомалиленд на карте серые и не кликаются (у них нет ISO-кода).

## Как добавить паспорт

1. Добавить запись в `scripts/passports.json`: `{ "code": "PL", "iso3": "POL", "name": "Польша" }`.
2. `npm run build:data` и проверить статистику в логе.
3. Пункт в селекте появится автоматически.

## Оверрайды

`data-src/overrides.json` — ручные правки поверх источника (союзные режимы ЕАЭС, красный статус «въезд закрыт», срок VOA в `note`). Поле `reason` обязательно; скрипт предупреждает, если оверрайд совпал с источником. Оверрайды ЕАЭС и Союзного государства (BY, KZ, RU, KG, AM) ещё не заполнены: их добавляет владелец проекта после ручной проверки.

## Деплой

GitHub Pages через `.github/workflows/deploy.yml` (push в `main`, раз в неделю по cron, вручную). В настройках репозитория: Settings → Pages → Source: GitHub Actions. PR проверяет `.github/workflows/ci.yml`.
